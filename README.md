## ไฟล์ในโฟลเดอร์

```
index.html      หน้าเว็บ (เนื้อหาทั้งหมดแก้ที่ไฟล์นี้)
img/            รูปส่วนหัวและรูปตกแต่ง
pdf/            ที่เก็บไฟล์ PDF (ถ้าไม่ใช้ Google Drive)
.nojekyll       ให้ GitHub Pages ส่งไฟล์ตามเดิม ไม่ต้องลบ
```

## ขึ้นเว็บด้วย GitHub Pages (ทำครั้งเดียว)

1. สร้าง repository ใหม่บน GitHub ตั้งเป็น Public
2. กด **Add file > Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ img และ pdf) ไปวาง แล้วกด **Commit changes**
3. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที ลิงก์เว็บจะขึ้นด้านบนของหน้า Pages ในรูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

## เพิ่มสไลด์หรือการบ้าน

เปิด `index.html` บน GitHub (กดรูปดินสอเพื่อแก้) แล้วหาส่วน `ตั้งค่าโดยอาจารย์` ที่อยู่ช่วงท้ายไฟล์

**วันเริ่มเทอม:** แก้บรรทัด `var START=new Date(2026,10,16);`
เดือนนับจาก 0 คือ มกราคม = 0 ไปจนถึงพฤศจิกายน = 10 ปีใช้ ค.ศ.

**สไลด์:** ใส่ในวงเล็บเหลี่ยมช่องที่ 3 ของสัปดาห์นั้น

```js
[2,"บทที่ 1 บทนำ... (ต่อ)",[["สไลด์บทที่ 1","https://drive.google.com/file/d/xxxx/view","5 MB"]]],
```

- ถ้าใช้ Google Drive ต้องตั้งแชร์เป็น "ทุกคนที่มีลิงก์ดูได้"
- ถ้าเก็บไฟล์ใน GitHub ให้อัปโหลด PDF ไว้ในโฟลเดอร์ `pdf/` แล้วใส่ `"pdf/ชื่อไฟล์.pdf"` แทนลิงก์ Drive ปุ่มดาวน์โหลดจะขึ้นเอง
  ตั้งชื่อไฟล์เป็นภาษาอังกฤษไม่มีเว้นวรรค เช่น `w02-slide.pdf` และแต่ละไฟล์ต้องไม่เกิน 25 MB ถ้าอัปโหลดผ่านหน้าเว็บ GitHub
- ใส่หลายไฟล์ในสัปดาห์เดียวกันได้ คั่นแต่ละไฟล์ด้วยจุลภาค (,)

**การบ้าน / Quiz:** แก้บรรทัด `var HW={};` โดยใช้เลขสัปดาห์ที่เปิดให้ส่งเป็นตัวนำหน้า

```js
var HW={
  4:{name:"Quiz 1 (บทที่ 2)",note:"ต้องล็อกอินบัญชี Google ก่อนตอบ",url:"https://forms.gle/xxxx"},
  6:{name:"Quiz 2 (บทที่ 3)",note:"",url:"https://forms.gle/yyyy"}
};
```

ก่อนถึงสัปดาห์นั้น การ์ดจะแสดงแค่ "เปิดส่ง สัปดาห์ที่ X" พอถึงสัปดาห์นั้นจึงจะมีปุ่มไปที่แบบฟอร์ม

กด **Commit changes** แล้วรอประมาณ 1 นาที เว็บจะอัปเดตเอง ระวังอย่าลบเครื่องหมาย `"` `,` `[` `]` ไปด้วย ถ้าลบไปแล้วหน้าเว็บอาจขึ้นว่างเปล่า
